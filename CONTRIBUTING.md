# Contributing Guide

Thanks for your interest in contributing.

## Quick Start

1. Fork the repository
2. Create a branch from `main`
3. Install dependencies:

```bash
npm install
```

4. Run locally:

```bash
npm run dev
```

## Development Standards

- Keep visual design consistent unless the change explicitly requires design updates.
- Keep diffs focused and minimal.
- Use clear commit messages (Conventional Commits preferred).
- Do not commit secrets or private keys.

## Before Opening a PR

Run:

```bash
npm run lint
npm run build
```

Include in your PR:

- What changed
- Why it changed
- Screenshots or video for visual updates
- Any known limitations

## Pull Requests

- Link related issues when applicable.
- Keep PRs small and reviewable.
- Be respectful in code review discussions.
