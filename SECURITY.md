# Security Policy

## Reporting a Vulnerability

If you find a security issue, please do not open a public issue first.

Instead:

1. Open a GitHub security advisory (preferred), or
2. Contact the maintainer privately through GitHub profile channels.

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

## Response

The project aims to acknowledge reports within 72 hours and provide a remediation plan as quickly as possible.
