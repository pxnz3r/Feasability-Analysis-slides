# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent.
- Give helpful, actionable feedback.
- Focus on the work, not the person.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks
- Trolling, insulting, or derogatory comments
- Publishing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, or contributions that violate this Code of Conduct.

## Reporting

Report unacceptable behavior by opening a private security-style report as described in [SECURITY.md](./SECURITY.md).
